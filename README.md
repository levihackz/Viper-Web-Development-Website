# Viper Web Development — 5 Page Website

## Run it in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Easiest option: install the **Live Server** extension by Ritwick Dey, then right-click `index.html` → **Open with Live Server**.
4. Or simply double-click `index.html` to open it directly in a browser. The site uses plain HTML/CSS/JavaScript and does not require Node, React, Vite, Tailwind, npm, or a backend.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `portfolio.html` — Portfolio
- `contact.html` — Contact

## Change the company name
Open `script.js` and edit:
`const COMPANY_NAME = "Viper Web Development";`

## Important
The contact form currently validates and displays a local success message. It does not send email because there is no backend/email service connected yet.

Social links are intentionally placeholders and do not contain invented usernames.
Portfolio items are clearly marked as Concept Projects.
